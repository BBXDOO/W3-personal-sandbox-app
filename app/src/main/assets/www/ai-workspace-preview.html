ข้อเสนอจาก Qwen3

ยังไม่มีข้อเสนอ · ตรวจอ่านได้อย่างเดียว ไม่เขียนไฟล์

ส่งข้อความเฉพาะไปยัง API บนโทรศัพท์ที่ 127.0.0.1:8090 · ไม่มีการอนุมัติหรือเขียนไฟล์โดยอัตโนมัติ

เอกสาร / พื้นที่ข้อมูล

นำเข้า .txt, .md, .json, .csv, .html ขนาดไม่เกิน 1 MB ต่อไฟล์ เพื่ออ่านและแก้ไขในหน้าต่างนี้ ไม่เปลี่ยนไฟล์ต้นฉบับ

รายการเครื่องมือ / คู่มือ

กำหนดรายการและข้อความคำสั่งเองได้ เครื่องมือเหล่านี้เป็นแม่แบบ ไม่ใช่คำสั่งรันบนโทรศัพท์

คู่มือย่อ

1. นำเข้าเอกสารและเลือกอ่าน 2. จัดทำแม่แบบเครื่องมือ 3. ส่งออก JSON เก็บในพื้นที่ที่คุณเลือก 4. การเชื่อม Qwen3 จริงจะเพิ่มภายหลังเมื่อทดสอบการส่งข้อมูลอย่างปลอดภัย

ขอบเขต: ไม่แตะโครงการ Sandbox เดิม · ไม่มีการอนุมัติแก้ไฟล์อัตโนมัติ · ข้อมูลในหน้าต่างนี้อยู่ในหน่วยความจำชั่วคราวจนกว่าจะส่งออก
